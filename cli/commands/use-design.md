# Use Design System

Read @design.md and apply the design system in this conversation.

## Process

1. Read the full content of `design.md` from the project root
2. Announce which design tokens are now active (colors, typography, spacing)
3. For any UI work in this conversation, reference these tokens instead of hardcoded values

## Output format

Briefly summarize:
- Primary colors (top 3)
- Typography: base font and scale
- Key spacing values
- Any CSS framework detected

Then confirm: "Design system loaded. I'll use these tokens for all UI work in this conversation."
